# 耳机使用记录器（Headphone Logger）

Windows 常驻后台的耳机使用记录小软件：**场景切换时弹气泡确认**，自动按场景分段记录使用时长；区分**不同耳机**；托盘 + WebView2 图表看统计。

## 一句话目标

知道自己戴了多久耳机、哪些耳机分别用了多久，以及这些时间花在音乐 / 视频 / 游戏 / 网课 / 会议 / 编程上各多少。

## 核心特性

- **自动 + 气泡确认**：插入静默不打扰；前台跨场景切换（如网易云 → 哔哩哔哩）弹气泡确认，5 分钟无操作自动按检测值落库（标未确认）。
- **并发场景**：一边听歌一边打游戏 = 一个段两个标签，统计如实展示重叠（场景之和可大于总时长）。
- **分耳机统计**：按 Windows 默认输出设备（端点 ID + 友好名）归属会话，统计窗「设备」页看各耳机时长。
- **统计窗口（tab 化，不滚动）**：总览（今日/本周/本月卡片 + 场景饼图 + 每日柱状）· 时段（7×24 热力图）· 设备 · 明细（可改场景/并发标签/备注/确认状态）。
- **托盘常驻**：查看统计、开机自启开关、退出。

## 如何运行

前置：Windows 11、.NET 10 SDK（构建时）、WebView2 运行时（Win11 自带）。

```bash
dotnet restore
dotnet build -c Release
# 运行输出目录的 exe，或：
dotnet run --project src/HeadphoneLogger
```

运行后常驻系统托盘（右下角耳机图标）：
- 双击托盘图标 / 托盘菜单「查看统计」→ 统计窗口
- 托盘菜单「开机自启」「退出」

数据存于 `%USERPROFILE%\headphone-logger\headphone-logger.db`（SQLite，可随时删除；删除即清空记录）。

## 如何测试

```bash
dotnet test
```

覆盖：场景规则引擎、会话状态机（假音频设备/前台驱动）、统计聚合（并发场景重叠、本地日界、设备分组）。

## 技术栈

C# .NET 10 + WinForms · NAudio（IMMNotificationClient 监听输出设备变化）· Core Audio COM（发声进程枚举）· Microsoft.Data.Sqlite · WebView2 + ECharts（本地化，离线可用）

## 设备识别口径

默认渲染端点变化即视为「换耳机」：插入耳机 → 系统切到该端点 → 新会话记为该设备；拔出 → 端点回退 → 会话结束。蓝牙/USB/3.5mm 各自是独立端点，可区分不同耳机。

## 已知简化（v1）

1. 跨本地午夜的段，时长记入**段开始日**，不做跨日拆分。
2. 气泡超时/忽略一律标未确认（`confirmed=0`），统计仍计入。
3. 并发标签在场景切换时刻采样，不实时跟随（听歌中途停了，标签仍在）。
4. 统计窗为只读展示 + 明细修正，不做高级报表导出。
5. 场景规则表 `scene_rules` 存于数据库，暂无图形化编辑界面（可直接改库生效）。
